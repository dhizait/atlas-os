#### *1. PRODUCT PRINCIPLE*

#### *3. THE 3 DEMO SCRIPTS - "What Bank Sees"*

##### *DEMO 1: Business Launches Product in 5 Minutes* - BATCH-07C
1.  Login as "Product Manager"
2.  Open `Workflow Studio` → Drag: `[KYC Check] → [Open Savings Account] → [MNO Payout]`
3.  Click "Deploy to Atlas OS" 
4.  *ACCEPTANCE*: `workflow.yaml` appears in Git. Status = "Active". 0 developers touched.

##### *DEMO 2: Banker Runs the Bank* - BATCH-03,04,08B,09
1.  Login as "Teller"
2.  Create Customer: "Jane Doe, ID 12345"
3.  Open Account: "Atlas Flex Savings" from product catalog
4.  Deposit $1000
5.  Send $200 via ISO20022 to "Other Bank" 
6.  *ACCEPTANCE*: See `pacs.002` success. GL auto-posted. Event in stream.

##### *DEMO 3: IT Installs in 5 Minutes* - BATCH-05,06
1.  `git clone atlas-demo-bank`
2.  `docker compose up`
3.  Go to `localhost:8080` 
4.  *ACCEPTANCE*: Demo Bank is live with data. Can toggle ISO module off/on.

#### *4. TECHNICAL ACCEPTANCE CHECKLIST*

Before we call it "Take-Home", all must be ✅

*INSTALL*
- [ ] `docker compose up` boots in <3 minutes on 16GB RAM laptop
- [ ] 0 manual DB scripts. Bootloader seeds everything

*BUSINESS*
- [ ] Product Manager can create product without seeing code
- [ ] Workflow Studio has 10 base molecules: KYC, Account, Payment, Notification, etc
- [ ] `product.yaml` and `workflow.yaml` are human readable

*BANKING*
- [ ] GL is always in balance after any transaction
- [ ] Can send and receive 1 ISO20022 message end-to-end
- [ ] Customer 360 shows Accounts + Transactions + Events

*GOVERNANCE*
- [ ] Every transaction has `event_id` and `audit_hash`
- [ ] DevOps must approve `workflow.yaml` PR before it goes live

*PERFORMANCE*
- [ ] Payment API < 500ms p95
- [ ] Can handle 100 concurrent users on laptop
