*Unix is the blueprint for every good OS kernel — including Atlas OS.*

If we understand how Unix was built in 1969, we’ll build Atlas Kernel 10x faster and cleaner.

Here’s what to steal from Unix:

### *1. THE 5 UNIX IDEAS WE'RE COPYING DIRECTLY INTO ATLAS OS*
Unix Concept	What it Means	How it Maps to Atlas OS Kernel
**1. "Everything is a File"**	In Unix: disk, socket, printer = file you can read/write	**"Everything is an Event"** In Atlas: Customer, Account, Payment = `event.json` in BATCH-01. One way to talk to everything
**2. "Do One Thing Well"**	`ls` lists. `grep` filters. Pipe them together	**"Molecules"** BATCH-07C. KYC module does KYC. Payment module does payment. Chain them in Workflow Studio
**3. "Kernel Space vs User Space"**	Kernel = sacred. Stable. Fast. User apps can crash safely	**"KERNEL vs MODULES vs APPS"** BATCH-01 to 06 = Kernel. Can’t break it. BATCH-07+ = Modules. Banks can break them
**4. "Text Streams"**	All tools speak plain text. Easy to debug, grep, pipe	**"YAML + JSON"** All configs: `product.yaml`, `workflow.yaml`, `tenant.yaml`. Human readable, git-diffable
**5. "Small is Beautiful"**	Original Unix kernel = 10,000 lines of C	**"11 Batches for v1.0"** We’re not shipping 1000 modules. Ship tiny kernel, compose the rest
Unix won because it was simple, composable, and didn’t try to do everything.

Temenos lost that plot. We’re going back to it.

### *2. 3 UNIX LESSONS THAT SAVE US 6 MONTHS*

#### *Lesson 1: The Kernel Should Be Boring*
Unix kernel 1973: process, file, memory, device. That’s it.  
*Atlas Kernel*: Event, Registry, Account, AA, Toggle, Boot. That’s it.  
If we start adding "lending logic" to kernel, we’re dead. Keep it boring.

#### *Lesson 2: Pipes = Composition*
Unix power: `cat log | grep ERROR | sort | uniq`  
*Atlas power*: `[KYC Molecule] | [Account Molecule] | [MNO Pay Molecule]` in BATCH-07C  
Same idea. 50 years later.

#### *Lesson 3: Ship the Source + Tools*
Unix gave you C compiler + shell + man pages on day 1.  
*Atlas gives*: `docker-compose.yml` + `studio/` + `schema.json` on day 1.  
Bank can read it, fork it, fix it. No black box.

### *3. WHAT WE DON’T NEED FROM UNIX*

Unix was built for 1 user on 1 PDP-11. We have to add:

1.  *Multi-tenancy*: Unix had 1 `/etc/passwd`. We have 1000 `tenant.yaml`
2.  *Audit*: Unix had logs. We have BATCH-01 + BATCH-34 Chain Audit
3.  *ISO20022*: Unix never did payments. BATCH-08B is new

### *4. THE "UNIX PHILOSOPHY" FOR ATLAS TEAM*

Print this and put it on the war room wall for the 1-week sprint:

1.  *Rule 1*: Kernel code is read 100x more than written. Make it obvious.
2.  *Rule 2*: If you can’t explain it in 1 YAML file, it’s too complex.
3.  *Rule 3*: Write programs to handle text streams, because that’s a universal interface.
4.  *Rule 4*: Avoid captive user interfaces.
5.  *Rule 5*: Use tools in preference to unskilled help.

That last one = "Workflow Studio so BA doesn’t need dev"
