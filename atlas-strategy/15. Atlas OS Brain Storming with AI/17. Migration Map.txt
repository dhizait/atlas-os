### *3-STEP MIGRATION PLAN*

#### *STEP 1: SCAFFOLD + PLATFORM - Day 1*
1. Run the scaffold script
2. Move `pmf_` services into `platform/`
3. Get `docker-compose` running with Postgres + Kafka + Keycloak

#### *STEP 2: MIGRATE 1 DRIVER END-TO-END - Week 1*
Pick `customer` driver first. Lowest risk.
1.  Copy `cm001` to `cm010` code → `drivers/customer/api/`
2.  Extract any batch jobs → `drivers/customer/batches/`
3.  Point API Gateway to new driver
4.  Test: Old FE → New Driver. Keep DB the same for now

#### *STEP 3: DRIVER BY DRIVER CUTOVER - Week 2-6*
Priority order:
1.  `customer` → `product` → `core-banking` → `lending` → `payments` → `compliance`
2.  Last: move `integrations` and `intelligence`
3.  Once all drivers moved, switch DB from 1 big schema to `driver_name` schemas

### *KEY RULES DURING MIGRATION*
1.  *Strangler Pattern*: Old `svc101` and New OS run in parallel. API Gateway routes 10% traffic to new
2.  *DB First*: Don't split DB on day 1. Keep 1 DB, but use schemas: `core.accounts`, `customer.profiles`
3.  *Batches First*: Easiest win. Pull batches out first because they have no UI dependency

### *WHAT GETS DELETED*
`NG/wave-2.x`, `TM/_-mgt` folders with no code. Those were just placeholders. 
If `workflow-mgt` had real code it goes to `platform/workflow-engine`

### *2. `scripts/migrate_from_r01.py`* 
Auto-copies everything based on the map
import json, shutil, os, sys

OLD_ROOT = "../Atlas/releases/R01/work_desk" # Change this to your old repo path
NEW_ROOT = "."
MAP_FILE = "migration_map.json"

def copy_dir(src, dst):
    if not os.path.exists(src):
        print(f"SKIP: {src} not found")
        return
    os.makedirs(os.path.dirname(dst), exist_ok=True)
    if os.path.exists(dst): shutil.rmtree(dst)
    shutil.copytree(src, dst)
    print(f"COPIED: {src} -> {dst}")

def main():
    with open(MAP_FILE) as f:
        migration_map = json.load(f)

    print("=== MIGRATING PLATFORM ===")
    for item in migration_map["platform"]:
        copy_dir(os.path.join(OLD_ROOT, item["old"]), os.path.join(NEW_ROOT, item["new"]))

    print("\n=== MIGRATING DRIVERS ===")
    for driver in migration_map["drivers"]:
        driver_path = f"drivers/{driver['name']}"
        # Copy main services
        for svc in driver.get("services", []):
            copy_dir(os.path.join(OLD_ROOT, driver["old_root"], svc), os.path.join(NEW_ROOT, driver_path, "api", svc))
        # Copy external services
        for svc in driver.get("ext_services", []):
            svc_name = svc.split("/")[-1]
            copy_dir(os.path.join(OLD_ROOT, svc), os.path.join(NEW_ROOT, driver_path, "api", svc_name))
        # TODO: Manually move batch logic from services to batches/ folder

    print("\n=== MIGRATING APPS ===")
    for item in migration_map["apps"]:
        copy_dir(os.path.join(OLD_ROOT, item["old"]), os.path.join(NEW_ROOT, item["new"]))

    print("\nDONE. Review drivers/*/api/ and move batch logic to drivers/*/batches/")
    print("Next: docker-compose up -d && python scripts/run_driver_batch.py core.interest_accrual")

if __name__ == "__main__":
    main()
